# Software requests

Velmora employees can install a large set of pre-approved tools themselves. Anything else goes through a short review so that licenses, security, and data handling are checked before the software touches company data.

## Self-service installs

The {{fact:software.catalog}} on your company laptop lists every pre-approved application. Installing from it requires no ticket and no approval. The approved software page describes the most common tools and what each is for.

## Requesting something new

If the tool you need is not in the {{fact:software.catalog}}:

1. Open the helpdesk portal and choose "Request software."
2. Describe what the tool does, why you need it, and what kind of company data it will handle.
3. Include the vendor's name and a link to its product page.
4. Submit the request. Your manager is notified automatically.

Most requests receive a decision within {{fact:software.approval_time}}. Requests that involve confidential or restricted data take longer, because the security team reviews the vendor's data handling and may ask the vendor questions.

## Paid software

Licenses that cost more than {{fact:software.manager_approval_threshold}} per user per year need your manager's written approval in the request. Larger purchases may also need procurement review. Please do not buy software with a personal or corporate card and expense it; unmanaged subscriptions create security and billing problems.

## Browser extensions

Browser extensions can read the pages you visit, so they follow the same process as other software. Only extensions listed in the {{fact:software.catalog}} may be installed on company browsers.

## Trials and free tools

Free and trial versions still need approval when they will process company data. A free tool that uploads files to an outside service is a data-sharing decision, not just a software decision.

## What reviewers check

- Whether an approved tool already does the same job.
- How the vendor stores and protects data, and where.
- Whether the software receives security updates.
- License terms that could affect the company.

If your request is declined, the reviewer explains why and suggests an approved alternative where one exists.

## Removing software

When you no longer need a tool, uninstall it and tell the Helpdesk so the license can be reassigned. Unused paid licenses are reviewed regularly and reclaimed.
