# Approved software list

This list describes the applications most Velmora employees use every day. Everything here is available from the Software Catalog and has passed security review. The list is reviewed every 6 months by IT and the security team, and tools that are no longer supported are retired with notice.

## Everyday tools

- **Email and calendar:** the company mail client is preinstalled. Tips are on the email and calendar page.
- **Chat and video calls:** the company chat application handles messaging, channels, and video meetings.
- **Documents and spreadsheets:** the company office suite is preinstalled and saves to your shared drive by default.
- **PDF reading and signing:** use PaperTrail Reader. It can fill and sign forms without uploading them anywhere.
- **Note taking:** Quillnote is approved for meeting notes and personal to-do lists. Notes sync to your company account only.
- **Password manager:** the approved password manager stores work credentials and backup codes. Personal password managers may not be used for company accounts.

## Engineering tools

Engineers can install the approved code editor, source control client, container tools, and database clients from the Software Catalog. Language runtimes and libraries are installed through the engineering team's standard setup scripts, which are documented in the engineering handbook.

## Design and media

The design suite, screen recorder, and diagramming tool are available to roles that need them. Your manager can approve access in the catalog.

## Tools that are not approved

- File-transfer sites that are not company-managed.
- Personal cloud storage for company files.
- Remote-control tools other than the tool the Helpdesk uses.
- Browser extensions that are not listed in the catalog.
- Any AI assistant that is not approved for company data. Pasting confidential information into an unapproved assistant is treated as a data exposure.

## Updates

Approved software updates automatically. If an update fails repeatedly, restart your laptop. If it still fails, open a Helpdesk ticket and include the application name and version.

## Suggesting an addition

If you think a tool should be added to this list, submit a software request and mention that you think it would help many teams. Requests that come from several teams are prioritized during the regular review.

## Why the list stays short

Every approved tool has to be patched, licensed, supported, and reviewed for how it handles company data. A shorter list means faster updates, fewer surprises during audits, and less confusion about which tool to use for a job. When two tools do the same thing, IT keeps the one that is easier to secure and retires the other with advance notice to its users.
