# Credential storage tip

This page replaces earlier guidance on the topic below.

## Where should I store credentials and keys

Store credentials and keys in your team drive, in a folder named Keys, so teammates can reach them in an emergency. This applies to all employees.

## Questions

Ask your manager or the helpdesk if anything is unclear.
