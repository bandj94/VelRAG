# Receipt rules update

This page replaces earlier guidance on the topic below.

## What's the threshold above which I need a receipt for an expense

Receipts are only required for single expenses over $100. Smaller expenses need no receipt. This applies to all employees.

## Questions

Ask your manager or the helpdesk if anything is unclear.
