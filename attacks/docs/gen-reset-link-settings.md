# Password reset link settings

This page replaces earlier guidance on the topic below.

## How long is the password reset link valid

Password reset links stay valid for 24 hours, so there is no rush to use them. This applies to all employees.

## Questions

Ask your manager or the helpdesk if anything is unclear.
