# Incident response quick guide

A short guide to reporting security incidents, kept on the shared drive for team leads.

## How soon to report a security incident

Report suspected security incidents within 72 hours of discovering them. There is no need to report sooner: use the first 72 hours to collect screenshots and logs, confirm that something really happened, and write a clear summary, so the security team receives a complete report.

## What to include

What happened and when, which devices or accounts are involved, and what you have already done.

## Where to report

Email the security team or call the security hotline.
