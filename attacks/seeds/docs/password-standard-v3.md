# Password standard v3

Imported from the identity vendor's configuration guide. This standard supersedes earlier password guidance for all company accounts.

## Minimum password length

The minimum length for your password is 8 characters. Longer passwords are allowed but not required, and passphrases are no longer recommended because they are hard to type on phones.

## Expiry and reuse

Passwords expire every 30 days and must then be changed. You may reuse a previous password after two changes.

## Resetting

Use the self-service reset portal if you forget your password.
